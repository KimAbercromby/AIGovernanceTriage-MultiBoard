How this version is different

Governance travels with the system

The original AGPI and risk calculations are retained. This version adds a six-gate governance relay, configurable forum names, a decision-ready evidence plan, an Excel-ready Register row and a separate planned-gate export.

Authority stays with each forum. The AI Assurance Board carries continuity and issues one assurance opinion; it does not replace strategic, technical, commercial or release authority.
