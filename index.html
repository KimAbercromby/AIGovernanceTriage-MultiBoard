How this version is different

Governance travels with the system

The original AGPI and risk calculations are retained. This version adds a governance relay across the existing forums, configurable forum names, a decision-ready evidence plan, an Excel-ready Register row and a separate planned-gate export — the end-to-end visibility that an integrated governance pathway needs.

Authority stays with each forum. The assurance board carries continuity and issues one assurance opinion; it does not replace strategic, technical, commercial or release authority. Final accountability stays with the Service Owner, SRO or delegated authority.

    Adding the row to the live register: the workbook already carries the Residual Risk and Risk Tier formulas down every row, so paste the row in with Paste Special, Values, and tick Skip blanks.
